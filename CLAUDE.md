# QiTi-CNC — contexte pour Claude Code

Application « à la Easel », réécrite de zéro (aucun code d'Easel/Inventables ne doit être copié) : une page HTML **autonome** qui fait la FAO 2,5D à partir d'un SVG et pilote une CNC GRBL via **Web Serial**. Machine cible : TwoTrees TTC450 Pro. Relevé sur la machine de l'utilisateur (2026-10-29) : carte ESP32 « LaserBox_E » derrière un CH340 (USB 1a86:7523), GRBL 1.1h (VER 1.1h.2020101901), 115200 bauds, $130/$131/$132 = 450/450/80, vitesses max 750 mm/min ($110-$112), accélérations 400 mm/s², pas de homing ($22=0), fins de course actifs ($21=1), $30=31250. Broche : vitesse réglée au bouton du variateur, la carte ne fait que M3/M5. La carte peut rester muette après ouverture du port : la page propose alors un redémarrage par RTS (`watchSilence`).

## Règles
- Interface et messages **en français**.
- Éditer **`src/`** uniquement (`atelier-cnc.src.html` = HTML, CSS, utilitaires, réglages, projet, démarrage ; sections insérées par `/*INCLUDE:x.js*/` : `svg.js` import SVG, `fao.js` FAO + G-code, `temps.js` estimation, `materiaux.js`, `vue.js` canvas, `relief.js` vue « Relief » (carte de hauteurs balayée par la forme réelle des fraises, ombrée, en cache par `PLAN`), `panneaux.js` panneaux latéraux, `grbl.js` Web Serial, `gravure.js` déroulement d'une gravure), puis `npm run build` (régénère `dist/atelier-cnc.html`, à committer aussi). Garder chaque fichier court : sortir une section dans son propre fichier plutôt que d'allonger.
- Tout reste dans un seul fichier (HTML + CSS + JS vanilla, pas de framework, pas de CDN : la page doit marcher hors ligne). Seule dépendance : Clipper, intégrée au build.
- Après chaque modification : `npm test` (Playwright, ou Edge à défaut : `test/vcarve.test.js` vérifie les profondeurs, `test/grbl-simule.test.js` simule GRBL) et vérifier les captures `test/shot-*.png`.
- Sécurité machine : ne jamais émettre de mouvement sans Z de dégagement, jamais de G0 sous Z0 (approche rapide jusqu'à 0,5 mm au-dessus du brut, puis G1), garder la liste de vérification avant gravure, arrêter le flux sur toute `error:` ou `ALARM:` pendant une gravure.

## Architecture (sections du script, dans l'ordre)
1. **Réglages persistants** — matériau choisi (`S.material`, table et calcul dans `src/materiaux.js`, appliqué à toutes les fraises après confirmation) ; `S` (machine, brut, fraises, attaches, sens, origine) dans `localStorage` clé `atelier-cnc-v1`. Le dessin en cours (SVG, placement, usinages) est sauvegardé automatiquement sous `atelier-cnc-projet` à chaque `invalidate()` et restauré au démarrage. Fraises : `{id, name, type:'flat'|'v', d, angle, tip, feed, plunge, doc, so}` (`id` stable : les formes et les projets désignent leur fraise par id ; à l'ouverture d'un projet, une fraise est retrouvée par id puis par nom).
2. **Import SVG** — `importSVG()` : parse le SVG dans un conteneur caché, cumule les `transform` des ancêtres, `parsePathD()` maison (tous les cmd + arcs), discrétisation à 0,02 mm, conversion en mm via viewBox/width/height. Résultat : `shapes[{name, subpaths[{pts, closed}], op, depth, tool, clear}]` (`tool` = id de fraise, '' = fraise courante ; `clear` = fraise plate qui dégage le fond d'un remplissage en V) en coordonnées SVG (y vers le bas).
3. **FAO** (`src/fao.js`) — `computeCAM()` : `toStockFn()` place/inverse en coordonnées brut (y vers le haut, origine coin avant-gauche). Clipper (échelle 1000) : union pair-impair, offsets ±r, poches par offsets successifs. Orientation des boucles inversée selon conventionnel/avalant. `loopWithTabs()` pour les attaches. Entrée en rampe des fraises plates (`rampPts`, `S.ramp`) : allers-retours sur le début du tracé, jamais sous son profil (attaches). Remplissage en V (`vcarveCuts`) : par passe de profondeur L, anneaux de pente tous les `VSTEP` = 0,1 mm jusqu'à o = pointe/2 + L·tan(angle/2) (profondeur (o − pointe/2)/tan), puis fond plat à L. Élagage : un point d'anneau de pente à moins de dr de l'anneau suivant est couvert par le cône suivant (`clipOpen`) ; le dernier anneau de pente reste entier. `test/vcarve.test.js` vérifie entaille et manque de matière sur une grille. Formes ignorées dans `CAM.skipped` (affichées dans la liste). Poches et V : chaque anneau démarre au point le plus proche du précédent (`rotateTo`) et porte sa zone sûre `area` ; `buildGcode` enchaîne dans la matière si le segment reste dans cette zone (`segInArea`), sinon remonte. `shapeGroups()` par forme (avec sa fraise) ; `computeCAM()` renvoie `steps[{tool, groups}]` : une étape par fraise, plates (de la plus grosse à la plus fine) puis V, détourages (`outside`) dans une étape finale, étapes voisines de même fraise fusionnées. Dans une étape, groupes ordonnés on → pocket/vcarve → inside → outside. Dégagement (`clearCuts`) : poche à zMax là où le V atteint zMax ; le V ne reprend alors que les coins non atteints, au pas fin.
4. **G-code** (`src/fao.js`) — `buildGcode(step)` (un G-code par étape ; côté page `PLAN` = liste des étapes, `G` = étape choisie dans `#stepSel`, passage automatique à la suivante en fin de gravure) : coordonnées décalées par `originOff()` (centre ou coin), `moves[]` (pour l'aperçu, en coordonnées brut) et `lineMove[]` (ligne → mouvement, pour la progression).
5. **Vue** — canvas, vues « Dessin / Aperçu fraisage / Trajectoires », zoom molette, déplacement à la souris, sélection par clic (Maj = multi).
6. **GRBL / Web Serial** — objet `machine` : file `queue`, `inflight`, comptage de caractères (`RX_BUF = 127`), interrogation `?` toutes les 250 ms, `parseStatus()` (MPos/WPos/WCO/Ov), commandes temps réel (`!` `~` 0x18 0x90-0x92). À chaque bannière `Grbl`, `$$` est lu (`readGrblSettings/applyGrblSettings`) : course, $30 et vitesse rapide appliqués à `S.machine`, accélérations/vitesses max/$11 dans `S.machine.plan`, utilisés par `planTime()` (`src/temps.js`, planificateur façon GRBL) pour l'estimation de durée.
7. **Gravure** — `startJob/feedJob/stopJob/abortJob/finishJob`. Arrêt sûr `safeStop()` / `checkStop()` : feed hold, reset seulement à `Hold:0` (sinon alarme 3), délai max 10 s ; bouton « Stop » du panneau Machine.

`window.__atelier` expose l'état pour les tests.
